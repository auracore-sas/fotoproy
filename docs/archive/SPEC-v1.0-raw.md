# 5. Arquitectura del Motor de Sincronización Offline-First

Dado que el trabajo de campo en subestaciones y áreas rurales carece de señal estable, el móvil opera autónomamente.

- **Captura Inmutable Local:** Al tomar una foto, se asigna un UUID cliente v4 y se guarda la foto comprimida (.webp) con sus metadatos en SQLite local.
- **Cola de Sincronización (Sync Queue):** Se crea una tarea en segundo plano con estado PENDING. La cola reintenta periódicamente mediante exponenciales backoffs cuando detecta conectividad (WiFi o 4G).
- **Carga Resiliente (Chunked Upload):** Las imágenes se suben directamente a Cloudflare R2 mediante Pre-signed URLs, liberando de carga pesada al backend API.
- **Resolución de Conflictos:** Sincronización basada en eventos append-only. No hay conflicto de edición ya que cada fotografía y pin es una entidad inmutable registrada por timestamp atómico.
